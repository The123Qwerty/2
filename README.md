# 2

2 is a probability based game forked from 10. You start with a 1 (probably) and you have to fill up boards by holding down the arrow keys.

The objective of the game is to get the 2 tile.

The game spawns all the tiles from 1-2 with increasing rarity. However, there are MANY other tiles the game can spawn, most of which are very rare.

Good luck, luck is all you need!
